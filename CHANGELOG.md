# Changelog

## 0.1.0
- First release, apt-based distributions only (Ubuntu, Linux Mint, Debian family)
- `run.sh` launcher installs python3 and optional tools via apt
- Checks: CPU, RAM, GPU and driver, audio, network, Bluetooth, storage, webcam, USB, touchpad, battery, boot mode, firmware errors
- WSL and VM detection
- `--json` export, `--version` flag
